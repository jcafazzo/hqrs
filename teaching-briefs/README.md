# HQRS 846 teaching decision library

Open [`index.html`](./index.html) for the eight-case comparison and full teaching briefs.

The page deliberately contains more material than should appear in the two-hour introductory lecture. The decision guide recommends a maximum of three full contemporary modules, with an optional short stress test, and identifies which older sequence each case could replace.

## Briefs

1. Pulse oximetry
2. Corridor care
3. Fatigue
4. Automated-dispensing-cabinet frameshift
5. Doloral `1 + 1 = 11`
6. Time-critical Parkinson’s medication
7. ESM v2 across four health systems
8. Electronic-prescribing procurement and safety learning

The editable research sources are in [`research/`](./research/). Rebuild the HTML from the repository root with:

```sh
./scripts/build-teaching-briefs.zsh
```

## Publication boundary

The briefs use attributed official figures and source excerpts for classroom preparation. Public-web publication should preserve the source labels and be reviewed separately from Canadian classroom fair-dealing use. The full lecture source remains local/private.
